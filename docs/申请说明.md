# 光子光核共创营 · 作品集说明

## 一句话

我用三个不同媒介的原创作品，分别验证同一件事：**把抽象规则变成可体验的空间、图像和工具。**

## 为什么是这三件

| 作品 | 媒介 | 验证的能力 |
| --- | --- | --- |
| 回声测绘 / ECHO SURVEY | Unity 3D + HLSL | 把“声呐”变成一套真实可玩的空间感知规则；实时着色、角色控制、程序化音频、运行时关卡 |
| 引力花园 / GRAVITY GARDEN | Canvas 2D + Web Audio | 大规模实时粒子、物理稳定性、交互反馈、声音与视觉的同步 |
| 字场 / TYPE FIELD | Canvas 2D + 生成算法 | 确定性生成、参数化设计、可导出工具、把审美规则写成代码 |

三件作品分别对应 **空间 / 动态系统 / 生成设计**，不是同一套东西换皮；同时都控制在可以独立完成的范围内，没有为了“看起来大”而堆功能。

## 技术亮点

- **回声测绘**：四组脉冲数据通过全局 shader 数组驱动，每个片元独立计算波前距离；不依赖烘焙光照，也不使用后处理伪造声呐。
- **引力花园**：9,000 粒子实时更新，使用批量 Path2D 降低 Canvas 状态切换；声音实时合成，无音频文件。
- **字场**：同一 seed 可复现；支持 PNG 和 SVG 两种输出；生成逻辑与 UI 解耦。
- 三件作品都没有使用游戏模板、教程工程或商业素材；代码和关卡由本人完成。

## 我能在共创营里做什么

- 快速把模糊概念做成**可玩/可交互的原型**，而不是停留在文档。
- 在 Unity 和 Web 之间做技术选型：什么适合 3D 体验，什么适合轻量网页传播。
- 关注“规则—反馈—节奏”的设计，而不只是堆视觉。
- 愿意做脏活：构建、性能、交互细节、可交付性。
