# 作品说明

## 01 · 回声测绘 / ECHO SURVEY

**类型**：Unity 第一人称空间感知体验  
**引擎**：Unity 6（6000.6.7f1），Built-in Render Pipeline  
**时长**：5–8 分钟  
**平台**：Windows x64

### 概念

一个没有光的测绘场。玩家看不见建筑，只能通过声呐理解空间。  
左键发出一次脉冲，声波以玩家为中心向外扩散；建筑的轮廓、柱子和地面会在波前经过的瞬间显形。目标是在这片黑暗里找到三座信标。

### 核心规则

- 玩家只能看见“声波正在经过的地方”，以及刚刚经过后留下的短暂余辉。
- 三座信标分别位于中央平台、东侧平台和北侧平台。
- 靠近信标即完成一次测绘；三座全部回应后结束。

### 技术实现

- **实时脉冲着色**：四组脉冲的 `xyz + 开始时间` 通过 `Shader.SetGlobalVectorArray` 注入自定义表面着色器；每个片元计算自己到波前的距离，生成环形显现和余辉。
- **网格显形**：以世界坐标生成稀疏建筑网格，只有被回声覆盖时才发光。
- **程序化音频**：声呐 ping 和低频环境音均由代码合成，无音频素材。
- **第一人称控制**：CharacterController + 鼠标视角，带轻微步行镜头起伏。
- **运行时构建**：不依赖预制场景，启动时生成整张地图，方便迭代关卡。

### 操作

WASD 移动 · 鼠标环视 · 左键脉冲 · Shift 慢走 · Esc 暂停

### 边界

这是一个 5–8 分钟的实验性垂直切片，不是完整商业游戏；地图规模、敌人和剧情都刻意保持很小，重点在“用声音看空间”这一条规则。

## 02 · 引力花园 / GRAVITY GARDEN

**类型**：实时粒子引力场 / 交互视觉  
**技术**：HTML5 Canvas 2D、Web Audio API、原生 JavaScript  
**平台**：浏览器

### 概念

一片 9,000 个粒子的星尘。鼠标是唯一的引力源；移动鼠标会改变引力中心，点击会释放一圈脉冲。粒子围绕指针形成旋涡，拖尾和声音让场变得可触摸。

### 技术实现

- 粒子位置/速度用 `Float32Array` 连续存储，单帧更新 9,000 个粒子。
- 引力、切向旋涡、阻尼、边界循环和中心回收力共同维持稳定形态。
- 拖尾通过半透明清屏实现；粒子轨迹批量合入少量 `Path2D`，降低 Canvas 绘制开销。
- Web Audio 合成低频持续音和点击脉冲；鼠标横向位置影响滤波频率。
- 引力、拖尾、密度可调；支持暂停、静音、截图、全屏。

### 交互

移动鼠标改变引力 · 点击释放脉冲 · 空格暂停 · 面板内可调参数

## 03 · 字场 / TYPE FIELD

**类型**：生成式字体海报工具  
**技术**：HTML5 Canvas 2D、Web Audio 无关、原生 JavaScript  
**平台**：浏览器

### 概念

输入一句话，把它变成一张独一无二的字体海报。每个种子都会生成不同的字形密度、流场和配色；同一个种子永远得到同一张图。作品把“排版”从手工摆放变成一个可调参的生成系统。

### 技术实现

- 自实现确定性 2D value noise / fBm，种子驱动所有字形位置、角度、缩放和颜色。
- 三种构图算法：流场、径向、波纹。
- 三种配色：纸本、夜场、蓝纸。
- 密度和扰动可实时调节；设置保存在 localStorage。
- 支持 PNG 和 SVG 导出；SVG 保留可缩放的文字元素。
- 中央标题区域留出纸面呼吸区，避免网格完全吞掉文字。

### 使用

1. 输入海报文字
2. 选择构图和配色
3. 调密度/扰动，或换种子
4. 生成，导出 PNG / SVG

### 边界

当前字形使用系统宋体/黑体，不包含自定义字体文件；这是一个海报生成工具，而不是完整的排版软件。
